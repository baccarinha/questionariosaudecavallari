#🩺 Questionário de Saúde — Sistema de Coleta de Dados

👉 **Acesse aqui:**
[Questionário de Saúde](https://baccarinha.github.io/questionariosaudecavallari/)

🎯 **Objetivo do Projeto**

Desenvolver um sistema web capaz de coletar informações relacionadas à saúde por meio de um questionário estruturado, permitindo organizar dados de forma clara e progressiva.

🧩 **Funcionalidades do Sistema**

|O sistema apresenta as seguintes funcionalidades:|
|--|
🩺 Página inicial de apresentação do questionário
👤 Coleta de informações pessoais
📏 Registro de dados físicos (altura, peso, pressão e frequência cardíaca)
🧬 Seleção do tipo sanguíneo
📋 Registro de histórico de saúde
👨‍👩‍👧 Histórico familiar
🏃 Registro de hábitos de vida
🧠 Coleta de informações sobre saúde mental
🔄 Navegação entre páginas do formulário
⬅️ Botões de voltar e avançar
📑 Organização em etapas progressivas
📱 Interface simples e acessível
🛠️ Tecnologias Utilizadas

|Este projeto foi desenvolvido utilizando:|
|--|
HTML5 — Estruturação dos formulários
CSS3 — Estilização visual das páginas
JavaScript — Navegação entre páginas e interatividade
GitHub Pages — Hospedagem do projeto
Inteligência Artificial (IA) — Apoio na criação da estrutura e organização das etapas
